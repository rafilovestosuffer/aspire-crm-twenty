Appendix A · Command reference

Building

CommandDoes
./infra/rebuild.shAll eleven build steps, gated. The whole laptop build in one command
./infra/rebuild.sh --destroyWipe the databases first, then build. Destroys data
./infra/up.shStart the stack. Generates any missing secret. Safe to re-run
./infra/up.sh --no-devStart without the mail catcher
./infra/up.sh --vpsStart with the server overlay
./infra/up.sh --downStop. Keeps all data
./infra/up.sh --destroyStop and delete every database and workflow. Requires typing DESTROY
